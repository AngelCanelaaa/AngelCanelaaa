### Detección de Fatiga en Conductores

Sistema de visión por computadora que detecta señales de fatiga en conductores a través de la cámara web. Modelo MobileNetV2 con Transfer Learning, 99.02% de precisión en test. Estrategia de doble predicción (región de ojos + cara completa).

Computer vision system that detects driver fatigue signals via webcam. MobileNetV2 model with Transfer Learning, 99.02% test accuracy. Dual prediction strategy (eye region + full face).

**Stack:** Python, TensorFlow/Keras, OpenCV, FastAPI, Docker

[Repositorio](https://github.com/AngelCanelaaa/deteccion-fatiga-conductores)

Full-stack application that converts temperatures using a Keras neural network model. Includes automatic fallback to mathematical formula when the API is unavailable.
